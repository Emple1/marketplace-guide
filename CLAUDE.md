## Принятые решения (не менять без запроса)

- На странице нет плашек версии и даты сборки; вместо буквы — логотип.
- Логотип ведёт на `home_url`, название в шапке — в начало страницы; круглая кнопка внизу — в конец.
- Списки-перечисления маркетплейсов из документа удаляются полностью (не превращаются в ссылки).
- У заголовков значок-скрепка, видимый при наведении (не «#»).
- Раздел «Введение» не сворачивается; сворачивается только оглавление (дерево).
- Прокрутка везде мгновенная, без `smooth` — иначе по пути начинают грузиться все скриншоты.
- Матрица функционала ведётся в Google Таблице, а не в Google Doc и не в коде.
- WebP — только без потерь: с потерями палитровые скриншоты получаются больше PNG.
- Яндекс Метрика и другие счётчики не используются.
- Клиентам даётся ссылка на сайт; однофайловая версия — только для ручной отправки.
- Шрифт и акцентный цвет — как на marketplace.is1c.ru: TildaSans (встраивается base64 из
  `fonts/TildaSans-VF.woff2`, внешних запросов нет), жёлтый `#f7c500` с чёрным текстом на заливке;
  цветной текст — тёмным оттенком `--accent-ink`, жёлтым текстом по белому не пишем.

## Известные проблемы в данных

- В Google Doc 11 битых ссылок «Более подробно о …» — разделы-цели удалены; сборка печатает список.
- В «Приложении 1» ссылка «М.Видео» ведёт на «Инструкция Lamoda».
- 8 ссылок ведут на другие Google-документы (Google Drive) — оставлены как есть.
- `support_url` содержит `app_req_id=…` — может оказаться одноразовым; при поломке заменить на постоянный адрес.
- Отметки в матрице функционала требуют проверки: ячейки «?» и строки «Перечень функционала» /
  «Основной функционал модуля» (сейчас только WB).
- У «Магнит Маркет» нет своих разделов, поэтому кнопки фильтра нет.
- Абзацы вида «На МегаМаркет: …» внутри общих разделов фильтр не скрывает (нет отдельного заголовка).

## Окружение и приёмы

- Windows, Git Bash + PowerShell, Python 3.13 локально (3.12 в Actions). В скриптах —
  `sys.stdout.reconfigure(encoding="utf-8")`.
- Файлы проекта с CRLF: при записи из Python сохранять переводы строк (`newline=""`).
- В bash-heredoc последовательности `\b`, `\x89` и т. п. превращаются в управляющие символы —
  код с обратными слэшами писать во временный файл через Write.
- `gh` на компьютере не установлен: публикацию запускать кнопкой Run workflow на GitHub,
  состояние запусков — через `https://api.github.com/repos/Emple1/marketplace-guide/actions/runs`.
- Проверка в браузере: `python -m http.server` по `dist/web` или `site/` (через `file://` не работает `fetch`).
  В скрытой панели браузера `IntersectionObserver` и анимации приостанавливаются — прокрутку проверять
  через `dispatchEvent(new Event('scroll'))` или после скриншота.
- Проверка «Что нового» локально: подложить изменённые `sections.json`/`changes.json` в папку, поднять
  на ней сервер и запустить `python tools/check_and_prepare.py http://localhost:<порт>`.
- Коммиты на русском с подписью `Co-Authored-By`, после правок — `git push`.
